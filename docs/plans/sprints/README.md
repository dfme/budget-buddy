# Sprint-Planungen

Ein Dokument pro Sprint, abgelegt von [`/plan-sprint`](../../../.claude/skills/plan-sprint/SKILL.md)
als `SPRINT-NN.md` (zweistellig: `SPRINT-04.md`).

Liegt bewusst **unterhalb** von [`docs/plans/`](../README.md) statt als eigenes Top-Level-Verzeichnis:
es ist dieselbe Familie von Planungsartefakten, nur eine Ebene höher — pro Sprint statt pro Issue.
Der Plan-Index globt nicht rekursiv, dieses Verzeichnis taucht dort also nicht auf.

**Das Dokument ist der Vorschlag, nicht die Wahrheit.** Führend für die Sprint-Zugehörigkeit ist
das Iteration-Feld `Sprint` im [Sprint Board](https://github.com/users/dfme/projects/4) — hier
steht der Stand zum Zeitpunkt der Planung, inklusive Begründung, kritischem Pfad und dem, was
bewusst nicht in den Sprint kam. Verschiebt sich während des Sprints etwas, wird das im Board
nachgeführt, nicht hier: das Dokument bleibt als Planungsentscheid stehen.

Milestones werden für Sprints **nicht** verwendet (siehe CLAUDE.md, „Sprint-Planung: Iteration-Feld
ist führend").

## Historie

Die Planungen für Sprint 1–3 entstanden vor diesem Skill als freie Prompts und liegen weiterhin
unter `docs/prompts/` (`05_01_prompt_planning_sprint_2.md`, `..._sprint_3.md`). Sie werden nicht
nachträglich hierher migriert — sie sind Teil der Kursdokumentation und dort im Kontext ihrer
Prompt-Historie richtig aufgehoben.
