0:30 Stolperstein $0.95 für einen Bericht

Der Agent zahlte für Kontext, den er nie brauchte

Das Problem

Der erste Lauf des Berichtsagenten kostete $0.95, riss das Budget und brach mit einem Traceback ab. Für einen Text von 200 Wörtern.

Nicht das Denken war teuer: 274'000 Input-Tokens bei 1'900 Output-Tokens, Thinking-Tokens 0.

Die Lösung

setting_sources steht im SDK per Default auf ["user","project"]. Die CLI lud CLAUDE.md, die Projekt-Skills und alle installierten Plugins mit — rund 88'000 Tokens pro Request.

Mit setting_sources=[] und effort="low": $0.17.

Wichtiger als die Kosten: ohne diese Zeile hängt das Verhalten davon ab, wer den Agenten startet und was lokal installiert ist.

Und zwei kleinere: @tool gibt ein SdkMcpTool-Objekt zurück, keine Funktion — im Test ruft man .handler(args) auf. Und der Backend-Prompt verlangt «nur ein Kategoriename», der Agent muss aber mehrere Transaktionen beantworten: Formatierung gehört in den Code, nicht in den Prompt.
